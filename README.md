# Invitación de boda V1

Web estática preparada para GitHub Pages.

## Publicarla en GitHub Pages
1. Crea un repositorio nuevo en GitHub.
2. Sube todos los archivos manteniendo la carpeta `assets`.
3. Ve a `Settings > Pages`.
4. En `Build and deployment`, selecciona `Deploy from a branch`.
5. Selecciona la rama `main` y la carpeta `/root`.

## Personalización rápida
- Nombres, fecha, dirección y textos: `index.html`.
- Colores y diseño: variables al principio de `styles.css`.
- Fecha de la cuenta atrás: atributo `data-date` en `index.html`.
- Integración con Google Sheets: se añadirá en `script.js` cuando esté disponible el enlace o Apps Script.
